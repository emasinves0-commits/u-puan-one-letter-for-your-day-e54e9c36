# One Letter for Your Day

This entry writes exactly one letter — **Z** — to `entry.txt` and nothing else. Behind Z sits the word for the day: **zombie**, a sleep-dead day (zero sleep, zonked, Zzz).

## How it works

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This creates `out/entry.txt` containing exactly the single character `Z` with no trailing newline.
